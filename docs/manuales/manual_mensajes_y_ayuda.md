# Manual de Usuario — Mensajes, Centro de Ayuda y Tutorial

Tres módulos pensados para que nadie se quede bloqueado sin saber qué hacer
(carnet inactivo, foto rechazada, datos mal registrados) sin tener que buscar
a alguien en portería.

## Mensajes

Menú lateral → **"Mensajes"**.

- Es **un solo hilo por persona** con los administradores/asesores: todos los
  asesores ven y responden el mismo hilo.
- Sirve para preguntar y para recibir avisos: cuando un administrador rechaza
  o aprueba una foto, el motivo llega **también** aquí (además del correo),
  y se puede responder en el mismo hilo.
- El menú muestra un contador de mensajes sin leer; se marcan leídos al abrir
  el hilo.
- Límites: 2000 caracteres por mensaje y un tope de envíos por hora para
  evitar abuso.

### Bandeja del asesor

Quien puede asesorar (rol Admin, o rol Usuario con cargo **Administrador** o
**Administrativo**) atiende los hilos desde **"Bandeja de Mensajes"**: lista
de personas con conversación, con lo último escrito y cuántos mensajes
esperan respuesta (primero quien lleva más tiempo esperando). El enlace del
menú solo se pinta para rol Admin; los demás asesores entran por la URL
`/admin/mensajes`.

## Centro de Ayuda

Menú lateral → **"Centro de Ayuda"**.

- **Preguntas frecuentes** organizadas por categoría (carnet, foto, datos,
  equipos, acceso, privacidad), con las respuestas alineadas con el
  funcionamiento real del sistema.
- **"Contactar a un asesor":** formulario con un asunto predefinido (carnet,
  foto, datos, inicio de sesión, equipos u otro) y el detalle. El mensaje se
  crea en su hilo de **Mensajes**, donde llegará la respuesta.

## Tutorial de primer ingreso

- Al entrar por primera vez, el sistema ofrece un **recorrido guiado** que
  explica el flujo completo: completar información → subir foto → esperar la
  aprobación del asesor → registrar equipos → usar el código de barras en
  portería. Se muestra **una sola vez** (quede completado o saltado).
- La **versión en texto**, consultable siempre, está en el menú/página
  **"Tutorial"** (`/tutorial`), con ejemplos concretos de cada paso (cómo se
  escribe el documento, dónde está el serial del portátil, etc.).
